    <span class="tag">Go</span>

  </p>
  <ul>
    <li>Sources: GitHub, GitLab, Gitea, Forgejo, Codeberg · Tickets: Phasical, Jira, Linear (all from day 1)</li>
    <li>Ticket integrations with <strong>multiple project/team targets</strong> — each with its own open/done/cancelled/superseded mapping</li>
    <li>Open-ticket idempotency: default <code>supersede</code>; alternatives <code>merge</code> or <code>skip_if_open</code></li>
    <li>Notifications via Shoutrrr (Slack, ntfy, …) — no custom chat integrations</li>
    <li>Admin UI for repos, integrations, ticket projects, notifications, poll interval</li>
    <li>CI: entrypoint workflows + reusable CI/release/image build (dev → nightly, main → VERSION draft, release → GHCR)</li>
    <li>Baseline / skip / create — no ticket on first sight of a repo</li>
  </ul>
